## Server-side rendering (SSR) and dynamic content

Next.js shines in use cases that require dynamic content. It allows you to render pages on the server at request time, which is useful for:

    Pokedex page
    Pokemon details page

## API Routes

Features to be implemented that rely on Nextjs specificities: 

    Full-stack login
    Backend For Frontend (BFF) pattern
    Session aware id encryption
