## Why Redis

![image](https://github.com/user-attachments/assets/9cbdedd7-e9a4-4710-81e6-cc6e2fb0ab7c)

I love the BFF (Backend For Frontend) Pattern and there is room for working as a fullstack so why not to have some cache and a valid session? 😁

Backend for Frontend pattern can prevent software architectural designs from having an API Gateway. It's main goal is to provide performance and a wise use of the cloud resources.

I'll pretend the pokedex service is a microservice for data and have this redis datalayer to have a better use of the pokemon database.
